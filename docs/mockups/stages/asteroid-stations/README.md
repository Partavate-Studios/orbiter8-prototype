# Asteroid station proposals (2026-11-18)

Three systems for a station built on an asteroid, in the game's flat white station style rather than the
illustrated base in `assets/art/asteroid-station.svg` (Koda: "it has a different style"). Drawn by
`../gen-stations.py` over the game's own rocks, with the planet stations' module shapes (pods, turrets,
yard frame), so the two read as one family. Mining is a derrick with small drones.

- **A, Surface base:** built across the rock's face: a hex landing pad and a dome (Platform), a derrick
  and drones (Mine), pods on a jetty (Port), turrets on the ridge (Armory), a yard frame off the edge.
  Pairs best with planet system B.
- **B, Tethered:** a small hub (planet system B's, in miniature) hovers off the rock on a tether; the
  drill works below and drones climb the line; the hub grows pods, turrets and a yard. Pairs with
  planet B or C.
- **C, Clamp ring:** a ring clamped around the asteroid: drills bite in from the ring, pods dock at one
  end, turrets at the other, a yard frame hangs below. Pairs with planet system A.

Files: `system-x.svg` (the sheet: every stage, at game size, the parts) and `system-x-<part>.svg`
(standalone, 120 units square, centered, laid over the rock): `platform`, `mine`, `port`, `armory`, `yards`.
